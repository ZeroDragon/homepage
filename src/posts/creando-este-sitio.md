## Este es el primer post

Este sitio es un proyecto en creación. Estoy usando [HARP](http://harpjs.com/) para compilar al vuelo [CoffeeScript](http://coffeescript.org/), [Stylus](http://learnboost.github.io/stylus/) y [Jade](http://jade-lang.com/), todo corriendo sobre [NodeJS](http://nodejs.org/). De tal forma que el resultado final debe ser **SEO Friendly**.

El blog lo estaré haciendo desde cero, estoy usando [MongoDB](http://www.mongodb.org/) como mi base de datos y [MarkDown](http://daringfireball.net/projects/markdown/) como mi lenguaje de entradas.

Si quieren leer más los invito a pasar al blog.

¡Saludos!
